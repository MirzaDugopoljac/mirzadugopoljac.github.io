MIRSEV STUDIO WEBSITE

1) Open index.html in any browser.
2) To replace the logo, overwrite assets/mirsev-logo.png.
3) Replace the generic Instagram links in index.html with your real Instagram URL.
4) Replace the four project cards with your own project pages/images when ready.
5) You can publish this folder for free on GitHub Pages, Netlify or Cloudflare Pages.

The site is responsive and includes Turkish/English language switching.

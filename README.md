# Mirza Dugopoljac — personal portfolio

A responsive landscape architecture portfolio with English, Turkish and Bosnian content. The site is static HTML, CSS and vanilla JavaScript, ready for GitHub Pages. No frameworks or runtime dependencies are required.

## Local preview

Run `node scripts/preview.cjs`, then open http://127.0.0.1:8000.

## Editing

- `assets/js/projects.js`: project titles, descriptions, stories and gallery images in all three languages.
- `assets/js/i18n.js`: shared translations. Overrides for the editorial homepage and its interface labels are in `scripts/editorial.cjs`.
- `scripts/build.cjs`: shared page templates, navigation, footer and metadata.
- `scripts/editorial.cjs`: homepage sections, selected project records and EN/TR/BS editorial copy.
- `assets/css/site.css`: shared layout primitives.
- `assets/css/editorial.css`: dark reference-inspired typography, layered project viewer, editorial sections and responsive layouts.
- `assets/css/earth.css`: forest-green, moss, earth-brown and parchment palette, loading screen and motion styles.
- `assets/js/effects.js`: skippable homepage introduction, particle headline reveal, page transitions, layer tilt and scroll reveals. Effects respect reduced-motion preferences; loading exits after at most 3.2 seconds, even if assets are slow.
- `assets/js/home-projects.js`: project layer tabs, keyboard controls, translated project records and notes.
- `assets/js/terrain.js`: illustrative Canvas 2D contours, pointer response and pause/resume control. This is a visual study, not measured GIS data. Motion starts paused on small screens and with reduced-motion preferences, and suspends offscreen or in background tabs.
- `files/CV.pdf` and `files/Portfolyo.pdf`: downloadable documents.

After editing templates, project data or translations, run `node scripts/build.cjs` to regenerate the 12 HTML pages, then `node scripts/check.cjs` to check local links, images, headings and translation coverage. Commit the generated HTML alongside the source changes. Visitors do not need Node; the generated pages already include English content and working links without JavaScript.

The homepage follows a statement → thesis → three entry points → capability index → work registry → practice → project notes → contact sequence. The Plan / Experience / Analysis controls show existing project assets and link to their case studies. Portfolio counts derive from project data; there are no simulated visitor or performance statistics.

## Publishing

The production URL is https://mirzadugopoljac.github.io/. Publish through the repository's GitHub Pages configuration after reviewing the local preview. These development scripts do not publish changes.

`mirsev-studio-website/` and the legacy `portfolio/404.html` are separate older content and are not generated by the portfolio build.

The iTech showcase is generated from `scripts/itech.cjs`, styled with `assets/css/itech.css`, and animated by `assets/js/itech.js`. Its project images are served from itechtr.com and credited on the page.

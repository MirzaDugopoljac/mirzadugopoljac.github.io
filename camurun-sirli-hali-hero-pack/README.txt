Before publishing
1. Open index.html.
2. Find the Instagram link marked by the comment.
3. Replace href="#" with the exact Instagram profile URL.

The films are silent on purpose. Browsers only allow reliable autoplay when a
video is muted. The HTML also includes playsinline so it stays inside the page
on phones, plus a reduced-motion fallback for accessibility.
